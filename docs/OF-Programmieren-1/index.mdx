## Lernziele

:::info[Begriffe Erklären]
1. Sie können die Begriffe **Algorithmus**, **Syntax** und **Semantik** in eigenen Worten erklären.
:::

:::info[**Turtle-Befehle kennen und anwenden**]
1. Sie kennen die **Startposition und Blickrichtung der Turtle** zu Beginn eines Programms.
2. Sie kennen folgenden Befehlen und können diese für eigenen Code verwenden:
   1. `forward`, `backward`, `left`, `right` und `goto`
   2. `penup`, `pendown`, `pencolor`, `pensize`, `dot` und `hideturtle`
   3. `fillcolor`, `begin_fill`, `end_fill`
:::

:::info[**Programmstrukturen anwenden**]
1. Sie können Befehle (Unterprogramme) aus random und turtle importieren.
2. Sie können mit randint(a, b) eine zufällige ganze Zahl erzeugen und in einem Programm verwenden.
3. Sie können eine Folge von Anweisungen mit einer for-Schleife eine beliebige Anzahl Male wiederholen.
4. Sie können bei `for i in range(zahl):` den Wert von `i` für jeden Durchlauf bestimmen und die Schleifenvariable `i` in eigenen Programmen gezielt einsetzen.
5. Sie können in einem Python-Programm die **Definition**, den **Aufruf** und die **Parameter** eines Unterprogramms kennzeichnen.
6. Sie können Unterprogramme mit oder ohne Parameter definieren und aufrufen.
7. Sie können bei einem Unterprogrammaufruf die übergebenen Werte den einzelnen Parametern zuordnen und erklären, wie sich eine Änderung dieser Werte auf das Ergebnis auswirkt.
8. Sie können Python-Code lesen und anhand des Codes vorhersagen, welche Ausgabe oder Turtle-Zeichnung entstehen wird.
9. Sie können ein gegebenes Programm mithilfe von Schleifen, Unterprogrammen oder Parametern vereinfach. Das Resultat muss dasselbe bleiben.
10. Sie können für eine neue Zeichenaufgabe ein eigenes Turtle-Programm entwerfen und umsetzen. Wenn es nicht explizit vorgegeben ist, dann entscheiden Sie selbst, wo Sie for-Schleifen einsetzen, welche Schritte Sie in Unterprogrammen zusammenfassen und welche Werte Sie über Parameter verändern.
11. Sie können mit # einen Kommentar einfügen, um den Zweck eines Codeabschnitts zu erklären.
:::

:::info[**Fehler identifizieren und beheben**]
1. Sie erkennen in einem Python-Programm Fehler und wissen, wie diese zu beheben sind.&#x20;
2. Sie können anhand einer Fehlermeldung folgende Fragen beantworten: \
   Was ist der Fehler? Wo ist der Fehler? Wie können Sie den Fehler beheben?
:::

Zeichnen Sie eine Treppe mit 10 Stufen.

::::aufgabe[Aufgabe 3 - Treppe als Unterprogramm mit 3 Parametern]
Definieren Sie das Unterprogramm treppe().

- Das Unterprogramm hat 3 Parameter:
  - anzahlStufen -> bestimmt, wie viele Stufen gezeichnet werden
  - hoehe -> bestimmt, wie hoch die einzelnen Stufen sind
  - breite -> bestimmt, wie breit die einzelnen Stufen sind
- Das Unterprogramm treppe() zeichnet die Treppe in einer Wiederholung:
  - forward() dürfen Sie maximal 2x verwenden
  - left() und right() dürfen Sie maximal 1x verwenden
- Beginnen Sie bei der Koordinate (-200,-200)
- Es darf nur die Treppe sichtbar sein.
- Sie rufen die Treppe am Ende zweimal auf. Nutzen Sie dazu jeweils unterschiedliche Werte, die Sie für die Parameter verwenden.

```py live_py slim
```

:::details[Lösung]
```py live_py slim
from turtle import *

penup()
goto(-200, -200)
pendown()

def treppe(anzahlStufen, hoehe, breite):
    for i in range(anzahlStufen):
        forward(breite)
        left(90)
        forward(hoehe)
        right(90)

treppe(6, 10, 10)
treppe(6, 80, 80)
```
:::
