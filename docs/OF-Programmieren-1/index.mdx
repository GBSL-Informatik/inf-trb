## Lernziele

:::info[Begriffe Erklären]
1. Sie können die Begriffe **Algorithmus**, **Syntax** und **Semantik** in eigenen Worten erklären.
:::

:::info[**Turtle-Befehle kennen und anwenden**]
1. Sie kennen die **Startposition und Blickrichtung der Turtle** zu Beginn eines Programms.
2. Sie kennen folgenden Befehlen und können diese für eigenen Code verwenden:
   1.  „forward“, „backward“, „left“, „right“ und „goto“
   2. „penup“, „pendown“, „pencolor“, „pensize“, „dot“ und „hideturtle“
   3. ”fillcolor“, „begin_fill“ und „end_fill“
:::

:::info[**Programmstrukturen anwenden**]
1. Sie können Befehle (Unterprogramme) aus random und turtle importieren.
2. Sie können mit randint(a, b) eine zufällige ganze Zahl erzeugen und in einem Programm verwenden.
3. Sie können eine Folge von Anweisungen mit einer for-Schleife eine beliebige Anzahl Male wiederholen.
4. Sie können in einem Python-Programm die **Definition**, den **Aufruf** und die **Parameter** eines Unterprogramms kennzeichnen.
5. Sie können Unterprogramme mit oder ohne Parameter definieren und aufrufen.
6. Sie können bei einem Unterprogrammaufruf die übergebenen Werte den einzelnen Parametern zuordnen und erklären, wie sich eine Änderung dieser Werte auf das Ergebnis auswirkt.
7. Sie können Python-Code lesen und anhand des Codes vorhersagen, welche Ausgabe oder Turtle-Zeichnung entstehen wird.
8. Sie können ein gegebenes Programm mithilfe von Schleifen, Unterprogrammen oder Parametern vereinfach. Das Resultat muss dasselbe bleiben.
9. Sie können für eine neue Zeichenaufgabe ein eigenes Turtle-Programm entwerfen und umsetzen. Wenn es nicht explizit vorgegeben ist, dann entscheiden Sie selbst, wo Sie for-Schleifen einsetzen, welche Schritte Sie in Unterprogrammen zusammenfassen und welche Werte Sie über Parameter verändern.
10. Sie können mit # einen Kommentar einfügen, um den Zweck eines Codeabschnitts zu erklären.
:::

:::info[**Fehler identifizieren und beheben**]
1. Sie erkennen in einem Python-Programm Fehler und wissen, wie diese zu beheben sind.&#x20;
2. Sie können anhand einer Fehlermeldung folgende Fragen beantworten: \
   Was ist der Fehler? Wo ist der Fehler? Wie können Sie den Fehler beheben?
:::
