# Gemeinsam programmieren
:::info[Was passiert alles, wenn dieser Code ausgeführt wird?]
:::
:::info[Wie können wir den Code anpassen, damit die Wiederholung Teil des Unterprogramms ist?]
:::
:::info[Welche Ideen haben Sie, um das Programm weiter anzupassen?]
:::

<br />

```py live_py title=ausgangslage.py slim
from turtle import *

def stufe():
    left(90)
    forward(20)
    right(90)
    forward(30)

for i in range(8):
    stufe()
```
