# Konfigurierbare treppe()

Diese Seite wird für das Praktikum genutzt. Wir passen gemeinsam das Unterprogramm __treppe()__ an und machen dieses konfigurierbar.

:::aufgabe[Welche Eigenschaften der Treppe wollen wir konfigurierbar machen?]
:::

<br />

```py live_py title=treppe.py slim
from turtle import *

def stufe():
    left(90)
    forward(20)
    right(90)
    forward(30)

for i in range(30):
    stufe()
```
