# Microsoft Word
In diesem Kapitel lernen Sie die wichtigsten Funktionen von Microsoft Word kennen. Sie erfahren, wie Sie Texte formatieren, gestalten und speichern können.

Sie arbeiten dabei in ihrem eigenen Tempo und bauen auf Ihren individuellen Vorkenntnissen auf. Am Schluss dieses Kapitels haben Sie ein korrekt formatiertes Textdokument erstellt und dieses als PDF exportiert.

## Auftrag

Um dieses Kapitel abzuschliessen, erstellen Sie ein Word-Dokument mit einem kurzen Text. Sie formatieren den Text so, dass er den untenstehenden Anforderungen entspricht. Am Schluss exportieren Sie das Dokument als PDF. Dieser Auftrag ist eine **Einzelarbeit**.

Sie können auch diese unformatierte Vorlage verwenden:  <a href="/files/Textverarbeitung/unformatierte_Vorlage.docx" download="unformatierte_Vorlage.docx">👉 hier</a>

**Wenden Sie die Formatierungen, die Sie in den folgenden Kapiteln kennenlernen, in Ihrer Vorlage an.**

Kapitel: [**Absatz- vs. Zeilenwechsel**](./04-Absatz-vs-Zeilenwechsel.mdx)

1. Erstelle mehrere Absätze durch einen Absatzwechsel
2. Speichern Sie das Dokument **in Ihrer OneDrive** ab – und zwar so, dass Sie es jederzeit wieder finden.
3. Erstellen Sie in diesem Dokument einen kurzen Text (ca. 1-2 Seiten). Hier geht es noch nicht um den Inhalt: **Sie dürfen den Text deshalb auch aus dem Internet kopieren (z.B. Wikipedia) oder von KI generieren lassen,** um Zeit zu sparen. Gegebenenfalls müssen Sie Ihren Text später noch ergänzen, indem Sie beispielsweise Kapitel- und Unterkapitelüberschriften, Aufzählungen und nummerierte Listen hinzufügen.
