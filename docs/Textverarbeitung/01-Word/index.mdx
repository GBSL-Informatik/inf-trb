# Microsoft Word
In diesem Kapitel lernen Sie die wichtigsten Funktionen von Microsoft Word kennen. Sie erfahren, wie Sie Texte formatieren, gestalten und speichern können.

Sie arbeiten dabei in ihrem eigenen Tempo und bauen auf Ihren individuellen Vorkenntnissen auf. Am Schluss dieses Kapitels haben Sie ein korrekt formatiertes Textdokument erstellt und dieses als PDF exportiert.

## Ressourcen
Nebst den folgenden Artikeln in diesem Kapitel finden Sie hier einige nützliche Links, die Ihnen helfen, Microsoft Word besser zu verstehen und zu nutzen.
- [Textverarbeitung (ICT Gymnasium Kirchenfeld)](https://ict.mygymer.ch/textverarbeitung/)
- [Word-Hilfe (Microsoft)](https://support.microsoft.com/de-de/word)
- [Word Basics Video (YouTube)](https://www.youtube.com/watch?v=WawYp-_oRBg)

## Auftrag

Um dieses Kapitel abzuschliessen, erstellen Sie ein Word-Dokument mit einem kurzen Text. Sie formatieren den Text so, dass er den untenstehenden Anforderungen entspricht. Am Schluss exportieren Sie das Dokument als PDF. Dieser Auftrag ist eine **Einzelarbeit**.

Sie können auch diese unformatierte Vorlage verwenden:  <a href="/files/Textverarbeitung/Vorlage_Jugendsprache_unformatiert.docx" download="Vorlage_Jugendsprache_unformatiert.docx">👉 hier</a>

**Wenden Sie die Formatierungen, die Sie in den folgenden Kapiteln kennenlernen, in Ihrer Vorlage an:**

Kapitel: [Formatierungszeichen](./05-Formatierungszeichen.mdx)

1. Schalten Sie ein, dass **Formatierungszeichen** angezeigt werden.
2. Testen Sie die **unterschiedlichen Formatierungszeichen** im Text.

Kapitel: [Textausrichtung](./06-Textausrichtung.mdx)

1. Formatieren Sie mindestens einen Text **linksbündig**
2. Formatieren Sie mindestens einen Text **rechtsbündig**
3. Formatieren Sie mindestens einen Text **zentriert**
4. Formatieren Sie mindestens einen Text **als Blocksatz**

Kapitel: [Worttrennung](./07-Worttrennung.mdx)

1. Nutzen Sie die **Worttrennung** für mindestens einen Text

Kapitel: [Inhaltsverzeichnigs](./08-Inhaltsverzeichnis.mdx)

1. Erstellen Sie ein **Inhaltsverzeichnis**

Kapitel: [Fussnoten](./09-Fussnoten.mdx)

1. Erstellen Sie zwei **Fussnoten**

Kapitel: [Kopf- und Fusszeilen](./10-Kopf-und-Fusszeilen.mdx)

2. Ergänze Sie das heutige Datum in der **Fusszeile**

Kapitel: [Abbildungen](./11-Abbildungen.mdx)

1. Ersetzen Sie im Dokument \[Bild der Frankfurter Buchmesse einfügen] durch ein Bild der Frankfurter Buchmesse.
2. Ersetzen Sie im Dokument \[Bild eines Gamecontrollers für den Ausdruck «NPC» einfügen] durch ein Bild eines Controllers

Kapitel: [Urheberrecht und Lizenzen](./12-Urheberrecht-und-Lizenzen.mdx)

1. Lesen Sie das Kapitel durch.
